# KNIGHTS: LAST STANDING

Стилизованный трёхмерный средневековый аренный экшен от третьего лица (**Third-Person Arena Fighter, Free-for-All**) в духе современных low-poly retro игр.

Пять бойцов выходят на каменную средневековую арену — побеждает последний выживший рыцарь. Архитектура боевой симуляции (`src/core/`) полностью отделена от рендеринга (`src/render/`) и интерфейса (`src/ui/`), что позволяет напрямую переносить системы в **Godot 4** (`CharacterBody3D`, `SpringArm3D + Camera3D`, ресурсы классов) и масштабировать до сетевого мультиплеера.

## Возможности

- **Свободная камера от третьего лица (`CameraRig`)**: плавное следование, ограничение углов по вертикали, настраиваемая чувствительность, защита от прохождения сквозь стены и колонны арены.
- **Четыре уникальных класса рыцарей с повышенным запасом здоровья и по 2 способности (`1` и `2`)** (`src/config/classes.ts`):
  - **Класс A — Рыцарь с одним мечом (185 HP)**: связка рубящих ударов, заряженный удар сверху, блок мечом, перекат; **`[1]` Героический прорыв** (стремительный выпад с пробитием блока) и **`[2]` Обет стали** (круговой клич + лечение +30 HP + выносливость + +25% урона на 5 сек).
  - **Класс B — Рыцарь с двумя мечами (155 HP)**: серия из 3 атак, вихревой выпад, парирование с оглушением, рывок; **`[1]` Танец стали** (управляемый круговой вихрь на 3 удара) и **`[2]` Метательный клинок** (бросок 3D-кинжала на 15.5 м + ускорение +25% на 3.5 сек).
  - **Класс C — Рыцарь с копьём (165 HP)**: дальние выпады, отбивание древком, отступающий шаг; **`[1]` Выпад дракона** (пробивающий блок рывок на 4.4 м) и **`[2]` Круговой заслон** (круговой взмах алебардой 360° с отскоком назад).
  - **Класс D — Рыцарь со щитом и молотом (225 HP)**: мощные удары, раскол земли, широкий башенный щит, толчок щитом; **`[1]` Осадный таран** (рывок за щитом с фронтальной защитой и полным оглушением врага) и **`[2]` Гнев титана** (землетрясение 360° + Железный бастион -35% входящего урона и гиперброня).
- **Полноценная 3-фазная боевая система**:
  - Конечный автомат состояний (`Idle`, `Moving`, `Attacking`, `HeavyAttacking`, `Blocking`, `Dodging`, `HitReaction`, `Stunned`, `Dead`).
  - Фазы `Windup` (замах) → `Active` (активное окно хитбокса) → `Recovery` (восстановление), блокировка мгновенного разворота во время удара и защита от повторного урона одной цели за один взмах.
  - Отладочное отображение 3D-хитбоксов, секторов атак и состояний ИИ по клавише `F3` или в настройках.
- **Тактический искусственный интеллект ботов (`BotController`)**:
  - Оценка круговых угроз (защита от атак любого ближайшего противника и летящих кинжалов), уход от свалки в центре арены на фланги и верхние бастионы, контроль выносливости, развод на промах против гиперброни, вскрытие блоков и добивание раненых целей.
- **Большая двухуровневая крепостная арена с мостом (`44×44 м`, два яруса `y = 0 м` и `y = 4.0 м`)**:
  - Собранная из модульных 3D-моделей `.glb` каменного двора, решёток подземелья, двухуровневых крепостных стен, решётчатых ворот, четырёх широких каменных лестниц, западного и восточного бастионов и центрального высокого деревянно-каменного моста (по которому можно сражаться сверху, сбрасывать врагов через центральный проём вниз и свободно пробегать прямо под мостом!).
- **Реалистичный средневековый звук (90 бесплатных CC0-сэмплов + 3D-позиционирование, `SoundManager`)**:
  - Настоящие записи взмахов мечей, молотов и древкового оружия, многослойные удары по латам и кольчуге, глухие блоки щитом и звонкое стальное парирование, шаги по камню двора и деревянному настилу моста со звоном доспехов, раскол камня, боевые кличи, крепостной колокол и озвучка интерфейса.
- **Режимы и управление матчем (`MatchManager`)**:
  - Одиночный матч **5 бойцов Free-for-All** (1 игрок + 4 бота) и **Тестовый режим 1 на 1** (для отладки).
  - Обратный отсчёт, таймер с финальной фазой «Ярость Арены», режим наблюдения за живыми рыцарями после гибели игрока, таблица итогов и чистый перезапуск.

## Управление

| Клавиша | Действие |
| --- | --- |
| `WASD` | Движение относительно горизонтального направления камеры |
| `Мышь` | Вращение камеры вокруг персонажа |
| `ЛКМ` (нажатие) | Лёгкая атака / серия ударов |
| `ЛКМ` (удержание) | Зарядка тяжёлой атаки |
| `ПКМ` | Блок / Парирование / Отбивающий приём |
| `1` и `2` | Две уникальные классовые способности рыцаря |
| `Space` | Прыжок (позволяет перепрыгивать низкие барьеры и спрыгивать с моста) |
| `Alt` / `C` / `Ctrl` | Уклонение / Рывок / Отступающий шаг / Толчок щитом |
| `Shift` | Спринт (при наличии выносливости) |
| `F3` | Включить / выключить отладку хитбоксов и ИИ |
| `Escape` | Меню паузы и настроек |

## Запуск и проверка

```bash
npm install
npm run dev      # Запуск dev-сервера
npm test         # Запуск модульных и симуляционных тестов
npm run build    # Проверка типов TypeScript и сборка проекта
```
