# МИФЫ: ПРОБУЖДЕНИЕ

Браузерный 3D кооперативный boss-rush прототип для 2–5 игроков с камерой от третьего лица. Мифологические боссы вторгаются в реальные места на Земле. Персонажи, боссы и окружение построены из стилизованных low-poly геометрических форм.

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:3000`. Для совместной игры создайте отряд и отправьте союзникам код комнаты или ссылку-приглашение. Одиночная тренировка также доступна.

## Управление

- **WASD / стрелки** — движение относительно камеры с ускорением и инерцией
- **Shift** — спринт с расходом выносливости
- **Мышь** — прицеливание по поверхности арены
- **ПКМ + движение мышью** — свободное вращение камеры
- **Колесо мыши** — приближение и отдаление
- **Tab** — включить/выключить автоматическую фиксацию на боссе
- **ЛКМ** — базовая атака
- **Пробел** — рывок с короткой неуязвимостью
- **Q** — способность класса
- **R** — ультимейт при заряде 100%
- **E** — удерживать рядом с павшим союзником для воскрешения; павший может ползти
- **Esc** — показать/скрыть помощь

## Классы

- **Аргонавт** — ближний бой, высокий запас здоровья, защитная эгида.
- **Следопыт** — быстрые дальние атаки и веер стрел.
- **Оракул** — дальний бой и массовое лечение.

## Боссы

- **Минотавр** — Крит, Греция.
- **Анубис** — Гиза, Египет.
- **Фенрир** — Ютунхеймен, Норвегия.

Каждый босс имеет три фазы, телеграфируемые атаки и собственный набор приёмов. Здоровье босса масштабируется от числа игроков. Сосредоточенный урон заполняет шкалу оглушения: атака босса прерывается, а на 3 секунды он получает +25% урона. За урон и лечение заряжаются ультимейты классов: **Стена Арго**, **Ливень стрел** и **Перерождение**.

## Технологии

Node.js, WebSocket (`ws`), Three.js / WebGL, vanilla JavaScript и CSS. Сервер отвечает за состояние комнат и игровую симуляцию; клиент отрисовывает объёмный мир и отправляет ввод. Если хостинг блокирует WebSocket, клиент автоматически использует резервный HTTP long-poll транспорт с пакетной доставкой состояний и событий. Three.js и рендерер собираются в один локальный классический скрипт без внешнего CDN и ES-модульной цепочки. Для пересборки после изменения `renderer3d.js` используйте `npm run build` (это также выполняется при `npm run dev`).

### 3D-модели и арены

Все модели создаются процедурно из примитивов Three.js: без скачивания чужих моделей и без тяжёлого пайплайна ассетов. У классов разные силуэты, экипировка и анимация движения. У боссов собственные объёмные модели и реакции на атаки. Крит получил мраморные колонны и жаровни, Гиза — обелиски, пирамиды и песчаный ветер, Норвегия — снег, ели, скалы и горы.
