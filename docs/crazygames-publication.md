# CrazyGames — Basic Launch build

- Build: `npm run package:crazygames`. Upload `knights-crazygames.zip` as an HTML5 game, with `index.html` at the archive root. The Yandex and Beget builds are separate.
- Desktop/keyboard-and-mouse game: don't declare touch/mobile support until implemented and tested.
- SDK v3 loads from `https://sdk.crazygames.com/crazygames-sdk-v3.js` and is initialized before game startup. `loadingStart`/`loadingStop` bracket loading; `gameplayStart` is sent for the first playable match, `gameplayStop` for actual game breaks. SDK unavailability or timeout must not prevent guest play.
- Basic Launch does not serve ads. The CrazyGames build deliberately hides the rewarded-ad button and requests no ads; it has no real-money purchases. Match-earned coins and the three free / six unlockable heroes remain available. Monetization requires a later full-launch integration and review.
- Progress and settings are currently stored in browser `localStorage`. CrazyGames documents Automatic Progress Save (APS) as a possible localStorage backup; choose/confirm that option in the developer portal and test a guest, signed-in account, login/logout and two devices. APS has limitations and we have not verified it on the platform; do not claim guaranteed cloud saves. The CrazyGames Data module is **not** used, so don't select the Data Module option for this build.
- The build contacts `https://igra.cosmorox.ru` for multiplayer (PHP HTTPS relay), not a server inside the ZIP. Confirm CrazyGames permits this backend and test two actual players from CrazyGames, including sandbox/CORS and deployment availability. Solo play should still work without the backend. Beget is not automatically updated without credentials.
- Verify loading, gameplay start/stop, changing graphics settings, controls, guest progression, online, licenses and browser compatibility in the CrazyGames developer preview. Mock tests do not replace the actual CrazyGames SDK or review.
- Official docs: https://docs.crazygames.com/sdk/intro/ ; https://docs.crazygames.com/sdk/game/ ; https://docs.crazygames.com/requirements/technical/ ; https://docs.crazygames.com/requirements/ads/ ; https://docs.crazygames.com/other/aps/ .
